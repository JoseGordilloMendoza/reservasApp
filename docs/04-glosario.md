# 04 - Glosario

| Término | Definición |
|---|---|
| **Plataforma** | El sistema completo que operamos nosotros |
| **Negocio / tenant** | Cliente de la plataforma que recibe reservas (un complejo de canchas, un consultorio) |
| **Cliente final** | Persona que hace una reserva en un negocio |
| **Superadmin** | Usuario del equipo de la plataforma que administra negocios y suscripciones |
| **Recurso** | Lo que se reserva: una cancha, un profesional |
| **Servicio** | Tipo de reserva de un negocio, con su duración y reglas (por ejemplo "alquiler 1 hora" o "sesión 50 min") |
| **Disponibilidad** | Horarios en los que un recurso puede reservarse |
| **Bloqueo** | Horario que el negocio cierra manualmente (mantenimiento, feriado, uso propio) |
| **Reserva** | Registro de un cliente final en un recurso y horario, con un estado |
| **Reserva pendiente** | Reserva creada que aún no se confirma y que bloquea el horario por un tiempo limitado |
| **Expiración** | Paso automático de pendiente a expirada si no se confirma a tiempo |
| **Confirmación automática / manual** | Si la reserva se confirma sola o el negocio la aprueba |
| **Política de cancelación** | Anticipación mínima con la que el cliente puede cancelar o reprogramar |
| **Reserva recurrente** | Reserva que se repite (por ejemplo, todos los martes a las 19:00) |
| **Suscripción** | Pago periódico del negocio por usar la plataforma |
| **Link del negocio** | Dirección pública propia del negocio, donde sus clientes reservan |
| **Link de gestión** | Dirección única que permite al cliente ver o cancelar su reserva sin cuenta |
